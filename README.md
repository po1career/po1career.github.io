# PLK No.1 W.H. Cheung College — Career Team Website
# 保良局第一張永慶中學・升學輔導及生涯規劃組

A bilingual (English / 中文) website for the school's Career Team: study and JUPAS planning tools,
plus news on Local, Mainland and Foreign universities and Career Experience Activities.

- **Live site:** https://po1career.net
- Static website — HTML/CSS/JS, no backend, no build step. Fonts self-hosted (no third-party calls).
- Some tools are passcode-gated for students; passcodes are given out by the Career Team.

Contributing (people or AI agents): read [`AGENTS.md`](AGENTS.md) first. Every change goes through a
pull request and the automatic PR check.
